# How-to guides

Choose a guide for the change you want to make to an existing Tarn site:

- [Name your sections](name-sections.md): Map your existing folders to Tarn's section colours without renaming them.
- [Set or remove a page's badge](set-page-type.md): Override or hide a badge without changing the page's navigation.
- [Add a project logo](add-project-logo.md): Show your logo in the header and optionally add an icon for browser tabs.
- [Adjust a colour](adjust-colours.md): Override a theme colour in your own stylesheet.
- [Choose the default colour mode](set-default-colour-mode.md): Start new visitors in light or dark mode while keeping the colour toggle.
- [Self-host the fonts](self-host-fonts.md): Serve font files from your site instead of Google Fonts.
- [Use sidebar navigation instead of tabs](use-sidebar-navigation.md): Move top-level sections from header tabs into the sidebar.

For supported settings and defaults, see [Configuration](../reference/configuration.md).
For the colour variables, see [CSS custom properties](../reference/css-properties.md).
