your own documentation or application code under Apache 2.0. When redistributing
Tarn or modified theme assets, keep the applicable licence texts and notices,
and mark theme files you change. Tarn includes these notices automatically in
generated sites under
`assets/licenses/tarn/`. Keep that directory when distributing the site; you
can link to the files from your own legal notices page. The configurable Tarn
footer credit is optional; it does not replace licence notices. Apache 2.0 also
includes a patent grant and a patent
litigation termination clause, and grants no trademark rights. See the
[licence terms](https://www.apache.org/licenses/LICENSE-2.0) for details.

use SIL Open Font License 1.1; that licence does not apply to the documents made
with them. For local hosting, follow [Self-host the fonts](../how-to/self-host-fonts.md)
and retain the fonts' own licences.
